BUILT FOR REAL OPERATIONS

Connect to your infrastructure. Keep control of it.

Bring access governance into everyday operations, instead of adding it after the fact.

01

Organizations & user groups

Bind policies to organizations, targets, tags and user groups. Combine source IP checks with capability controls.

02

Command rules & AI review

SSH exec commands go through blocklists and allowlists first. Unmatched commands can use a configured LLM; model review errors fail closed.

03

Temporary SSH access

Create a time-limited grant for a service. Expiry or deletion closes its connections. The grant identifier is itself a sensitive access credential.

04

Command audits & terminal replay

Inspect commands, decisions and exit codes. Replay interactive sessions on a timeline when recording is enabled.

05

An MCP entry point for AI

Connect tools through /mcp. Token tool groups govern terminal and tunnel access; account and organization permissions still apply.

06

Private nodes & existing SSH

Add existing SSH services, or enroll private nodes with an Agent that connects outbound to the gateway.

A few things to know before you start

Does an AI agent need the target server’s private key?+

You do not need to give target credentials directly to the agent; the gateway manages them. Callers still need their own SSH identity, an MCP token or a controlled temporary grant.

Is a direct P2P connection guaranteed?+

No. It depends on the Agent version, browser, STUN configuration, network and firewall. Unavailable direct paths use relay. Web uploads retain a 1 GiB limit; download behavior also depends on browser capabilities.

Can I share temporary grants freely?+

No. Anyone holding the grant UUID can access its service during its lifetime, using the creator’s policies and audit identity. Share only with trusted recipients and delete it when finished.

Does command review guarantee safe operations?+

No. Rules, policy configuration and model output affect decisions. SSH exec review does not provide complete isolation of all interactive shell input. Use least privilege, capability controls and independent backups.

Is this a hosted service or software I deploy?+

This page describes self-hosted software. You deploy and configure the server, targets, databases, audit storage and optional LLM endpoint. Workspace visuals and data on this page are illustrative.
